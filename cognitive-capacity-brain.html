認知的キャパシティ, from First Principles

うまく願えない

仕事が比較的スムーズな日は、帰宅後の子どもの要求にも、少し間を置いて応じられる。同じ親なのに、締切と会議で頭がいっぱいの日は、声が先に出たり、感情を引っ込めてしまったりする。

「もっと優しくしよう」と決めても、その決意そのものが重い。自己啓発は、認知リソースを最適化せよ、回復せよ、気合で習慣化せよ、と同時に言う。どれも何かを救っていそうで、脳の中で何が有限なのかは見えにくい。

入口で必要なのは、理想の一日の完成図ではない。すれ違っている問題を、先に列にすることだ。

六つのすれ違い

  1. 同じ親なのに、日によって子への反応が変わる。性格や愛情の固定量だけでは、日次の揺れが残る。
  2. 「認知的キャパシティ」が有限に見える。だが有限なのが才能の総量なのか、同時に保持し制御する帯域なのかが混ざる。
  3. わかっている対応なのに、ストレス下では難しい。気合不足に聞こえるが、状態の切替かもしれない。
  4. 仕事の残りカスが家庭に滲む。怒りだけだと思い込むと、無口や愛情表現の減少が見えなくなる。
  5. 「意志のタンクが空」比喩は直観に合う。それでも、その比喩がラボで再現し、生理学と同じものかは別問題である。
  6. 回復せよ、という処方箋が同時に売られる。帰宅すれば戻るのか、頭が離れる必要があるのか、睡眠なのか、慢性の摩耗なのかが混線する。

この列は、答えの候補ではない。読者がこれから出会う主張を置くための、最初の摩擦面である。

入口で外す便利な錯覚

いちばん便利な錯覚は、良い親を一つの量として扱えるというものだ。そうすれば、増やせ、減らせ、最適化せよ、という言葉がすぐ使える。

でも、仕事負荷の高い日に親子の相互作用が変わるという観察は、愛の量の物語だけでは足りない。日次の状態が、応答の形を変える(*1)。

だから、ここではまだ部品名のカタログに飛びつかない。先に見るべきなのは、仕事の余裕と子への対応が連動して見える願いが、どの問題に割れているかである。

悪い日の自分を、性格の証拠だと感じるのは自然だ。声が鋭かった夜は、自分が冷たい親だったように思える。でも、その感じ方は、観測としては粗い。

日次で変わる応答

Repetti と Wood は、就学前の子どもを持つ母親を平日連続で追った。仕事の負荷や対人ストレスが高い日ほど、帰宅後の相互作用は、怒り一色というより、話し方が減り、愛情表現も減る——行動的・情動的な撤退が目立つ(*2)。

つまり滲みは、怒鳴りという一経路だけではない。無口も、短い返事も、タッチの減少も、同じ仕事日の残りカスの表れになりうる。後年の整理では、気分のキャリーに加え、社会的相互作用を避けたいという認知や、配偶者側の補償まで含めて読まれている(*3)。

得たもの：同じ親の日次変動を、「本質」ではなく状態と滲みの問題として置ける。失うもの：怒鳴らない日は余裕がある、撤退は愛がない、という単純道徳。適用範囲は、仕事と育児が同じ一日に重なる場面だ。性別や文化で表れは違うが、日次で応答が変わる、という問題自体は残る。

子への対応の話は、まずその日の親の状態から始まる。では、状態を制約している脳側の有限さとは何か。

「認知リソースが足りない」と言うとき、頭のスペックが低い、と聞こえることがある。だが、現場で折れるのは、しばしば別のものだ。子どもの話を聞きながら、仕事の未返信を思い出し、夕食の段取りを更新し、怒らない、を同時にやる——その同時性が重い。

保持と制御の帯域

作業記憶は、いま必要な情報を一時的に保持し、処理するための有限システムとして定式化された(*4)。後の整理でも、共通核は注意の制御と一時保持にある(*5)。Cowan は、注意の焦点に載るチャンク数が強く制約されると論じ(*6)、Engle は個人差の核を、干渉下で目標関連情報を保つ実行注意に置く(*7)。

Miyake らは、実行機能を更新・抑制・切替に分解しつつ、共通分散もあることを示した(*8)。「自制心」一語では、何が飽和しているのかが見えない。

シミュレーションを開く — 干渉下では同時に保持・制御できる帯域はすぐに飽和する

得たもの：認知的キャパシティを、無限の気合ではなく、同時保持と制御の帯域として扱える。失うもの：マルチタスク前提と、スペック信仰。適用範囲は、干渉・二重課題・情動負荷がある場面だ。自動化された習慣だけでは測れない。

有限なのは、同時に保持し制御する帯域である。では、なぜストレス下では、この制御が急に難しくなるのか。

優しい返し方は、頭では知っている。それでも、制御不能な忙しさの渦中では、知っている応答が届かないことがある。気合が足りないように感じる。感じ方としては正しいが、機構としては粗い。

反省から反射へ

Arnsten の総説は、かなり軽度でも制御不能なストレスが、前頭前野（PFC）の高次認知を急速に損なうことを整理する(*9)。高まったノルアドレナリンとドーパミンは、PFC のネットワーク結合を弱め、代わりに扁桃体や感覚・線条体寄りの制御を強めうる。脳は、反省的なトップダウンから、反射的なボトムアップへ状態を切り替える(*10)(*11)。

これは、危険に対しては生存上の意味を持ちうる。だが、子どもの些細な要求に、同じ切替が起きると、柔らかい抑制や視点取得が先に落ちる。

得たもの：ストレスを「気分が悪い」だけでなく、高次制御の一時オフラインとして読める。失うもの：気合不足や道徳的欠陥としての独占説明。適用範囲は、制御不能・不確実・評価圧のある負荷だ。単純な反射課題では別の話になる。ストレスは常に無能を意味しない。

ストレスは、しばしば反省をオフに近い状態へ切り替える。では、その状態は家庭で、怒りだけとして表れるのか。

仕事の残りカスが家庭に入ると、表れは一通りではない。ある夜は短い声になる。ある夜は、ソファの端で静かになる。どちらも「愛がない」証拠に見えやすい。見え方としては痛いが、観測としては足りない。

撤退と反応的ネガティブ

撤退は、短期には過負荷を下げるコーピングの面を持ちうる。同時に、話し方と愛情表現が減れば、関係の薄い相互作用が残る(*12)。トレードオフがある。

さらに、子どもの挑戦的な行動は、親の残っている制御を試す。Deater-Deckard らは、母親の作業記憶が低いと、子の反対・注意散漫への反応的ネガティブが顕著になることを示した(*13)。実行機能全般でも、親 EF が低いほど、子の問題行動と厳しい養育の結びが強く、家庭のカオスがその交差をさらに修飾しうる(*14)。枠組みとしては、親の情動・認知制御容量が養育の条件になる(*15)。

得たもの：家庭での難しさを、愛の量だけでなく、滲み経路と残存制御の交差として読める。失うもの：良い親／悪い親の固定ラベル、撤退＝冷淡の一択。適用範囲は、帰宅後の短時間相互作用だ。相関は運命ではない。個人を診断する道具にもしない。

家庭での難しさは、愛の量だけでなく残存制御と滲み経路の問題でもある。では、「意志のタンクが減った」で足りるのか。

「今日はもう空だ」と感じる夜がある。比喩としては強い。では、その空は、燃料タンクなのか。それとも別のものが落ちているのか。

競合する説明

Baumeister らの strength モデルは、自己制御が有限資源のように振る舞う、と主張した(*16)。日常の有限感と相性が良い。だが Inzlicht と Schmeichel は、枯渇を資源消費ではなく、動機と注意の一時シフトとして再記述した(*17)。さらに大規模な登録再現では、古典的なラボ効果が実質ゼロ付近に落ちた(*18)。後続の multisite でも、効果は検出困難寄りである(*19)。

ここでの要点は、「疲労は幻想だ」ではない。日常の有限感と、短時間ラボの枯渇効果と、Arnsten 系の生理学的オフラインは、レイヤが違いうる。タンク比喩は直観を運ぶが、機構の確定にはならない。

需要が止まると戻る／止まらないと残る

Meijman と Mulder の努力–回復は、努力が負荷反応を生み、需要が止まれば戻る、と置く(*20)。物理的に帰宅しても、頭が仕事のままなら、同じ機能系への需要は続きうる。Sonnentag と Fritz は、心理的離脱・リラックス・熟達・統制を回復経験として区別した(*21)。

睡眠は別経路を持つ。一夜の睡眠剥奪でも、扁桃体の反応が増し、内側 PFC との結合が落ちうる(*22)。気合で情動を抑える物語と、結合が弱まっている状態は、同じではない。

慢性側では、アロスタシス（変化による安定）の過使用がアロスタティック負荷になる(*23)。日次の戻しと、長引く摩耗は、同じ「回復」一語では潰れる。

得たもの：有限感を本物として残しつつ、説明モデルを分け、回復を負荷の反転として置ける。失うもの：タンク一択、帰宅＝回復完了、アプリで慢性が消える、という完成幻想。適用範囲は勤務後・夜間・週末の回復窓だ。育児そのものが需要であるときの緊張は、残る。

有限感は本物でも説明は一つではなく、回復は負荷の反転であって完成解ではない。では、新しい最適化主張をどの地図に置くか。

新しい主張は、速い。「朝に意志力ゲージを見て、ポモドーロでタンクを回復し、夜にマインドフルネスでコルチゾールを下げ、週末は良い親トレーニング」——どれも同じポスターに載せられる。載せられるからといって、同じ層の問題を解いているとは限らない。

層と軸

ここまでの導出を、層ラベルとして置く。

  1. 容量・制御（作業記憶／実行注意／EF）
  2. ストレス状態切替（PFCオフライン／反射寄り）
  3. 家庭への滲み（撤退・情動・認知キャリー・親EF交差）
  4. モデル競合（タンク vs 過程 vs 生理学）
  5. 回復と慢性（努力–回復・離脱・睡眠・アロスタシス）

教育用の木は入口の近似であり、厳密には多所属の知識グラフである。系譜の矢印と構成の入れ子は、同じ図に重ねない。

新主張を置くときは、三つの軸で足りることが多い。

軸問い
前提（Origin）有限帯域か、タンクか、気合か。何を前提にしているか
層（Locus）容量／切替／滲み／回復・慢性のどこを触ろうとしているか
圧力（Pressure）日次負荷、制御不能性、需要の非停止、商品化のどれに応答しているか

フロンティアの同時販売

いま目立つ未解決の見え方は、二つある。ひとつは、日常の有限感をどう説明するか——タンク、動機シフト、PFCオフライン、環境負荷削減が同時に売られる。もうひとつは、回復の売り方——離脱、睡眠、マインドフルネス、習慣アプリが並び、急性の戻しと慢性摩耗が混同されやすい。

得たもの：広告を是非で終わらせず、座標付けできる。失うもの：一枚のポスターで全部が解ける安心。残る未知は、ラボと日常の対応、個人差、育児場面での離脱の倫理である。

EX-place

入力: 「脳科学に基づく認知最適化アプリ：朝の意志力ゲージ、ポモドーロでタンク回復、夜は3分マインドフルネスでコルチゾールを下げ、週末は『良い親トレーニング』——と広告するサービス。」

操作: 上の三軸に主位置を置き、導出のどの問題の副作用・商品化になりうるかを1文で書く。複数所属可。

自己点検: 製品の是非で終わらず、タンク比喩／ストレス切替／滲み／回復のどれが圧力か言えているか。著者推奨を書いていないか。

EX-doubt

入力: Claim C1「認知リソースは1日タンクで、使い切ると枯れる」

操作: 共通事実／争点／測定／隠れた価値のうち、いちばん怪しい点と足りない証拠を書く。

自己点検: 日常の有限感とラボの ego depletion を同一視していないか。生理学的オフラインとタンクを混同していないか。全否定／全肯定で閉じていないか。

主張は分解できるが、記事は勝者を決めない。どの争点が自分の生活で一番効くかは、読者側に残る。

構造を掴んでも、問いが始まらなければ、主体性は商品側に戻る。以下は確認クイズではない。思考の開始点である。
